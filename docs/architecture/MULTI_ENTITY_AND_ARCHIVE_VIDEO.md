## 决策

- 自动化开关沿用 `AutoAcceptUniqueEntities`，含义是每个名称可确定身份，而不是每个 Gallery 只能匹配一个实体。允许多个确定的 Coser／Character／Work；一个名称对应多个 UUID 仍需人工复核。
- Coser 按建议的稳定顺序形成 Credit，名称／Alias 命中同一个 UUID 时去重。Archive 建议按外部路径中首次出现位置排序，不依赖数据库遍历顺序。
- 无明确角色归属时，全部确定 Character 挂到首位 Coser。其余 Credit 可没有 Cast，不再使用 `CAST_REQUIRED_FOR_EACH_CREDIT` 阻断激活；其它激活、安全和身份歧义门禁不变。
- Work 始终通过 Character 的主要 Work 派生，不新增独立 Work 与 Coser／Gallery 关系。确定的 Work 建议只用于角色身份消歧／确认上下文；没有 Character 时仍为 Album，不创建空 Cast。
- 自动关联只填充没有 Credit 的草稿，不替换人工／Manifest 关系，不删除已有 Tag。关系、建议状态、revision 和 Manifest dirty 必须一次事务提交。
- 存档视频允许探测、拍摄日期和 Poster。可证明安全的随机成员读取优先；否则只为后台派生临时提取，用后清理，不长期保留视频原件。
- 存档播放不提取、不 Remux、不转码。必须同时满足安全直接成员访问和浏览器兼容矩阵；否则明确说明原因并提示用户自行解压。播放能力不足不阻断整个 Gallery 激活，结构性安全错误仍阻断。
- ZIP Store／普通 TAR 可提供受限成员 Range；7z Store 不等于已证明可随机读取，须验证实际布局与偏移。无法证明时明确拒绝直放，不能把解压流冒充零复制访问。

### 2026-09-30 编辑页人工匹配补齐

- 角色默认挂首位Coser不变；存在多个人物时，每个Character行提供“所属人物”快捷切换，只把该Cast从原Credit移至目标Credit末尾，保留Character所属Work上下文及其他关系。未选择人物、未选择角色或目标已有同一Character时禁止切换；需“保存全部关系”才持久化，不修改实体本身的所属Work。
- 重复限制只针对同一Credit内重复Character；不同Coser允许扮演同一Character，不做跨Credit排他限制。目标已有角色时禁止把另一条移入，原有两个人物的角色关系均保留。
- 共享实体搜索候选列表点击搜索区域外、键盘焦点离开或Esc时关闭；列表内部点击不提前关闭，选中后关闭。异步结果返回不得自动重新打开已关闭列表。

- 编辑页来源名称候选不再限于MARKER导入：任何DIRECTORY来源以根目录名匹配；ARCHIVE以去除已支持存档扩展名的文件名及所属媒体库内的外部父目录名匹配，不使用媒体库根名称、宿主机祖先、Gallery手工标题或存档内部路径，不读取媒体／存档内容。
- 复用既有Unicode规范化名称／Alias包含匹配、短名保护、UUID去重、长名优先和歧义抑制；这是人工参考提示，不放宽自动化的精确身份匹配。Coser／Character独立展示；已匹配Work只作角色消歧上下文，Character继续携带所属Work，不建独立Work关系。
- 应用只更新页面关系草稿，保存全部关系后才写入，关闭／重新打开以已保存状态为准。Character候选无Coser时仍显示，但须先选择首位Coser才能应用；多Coser时挂首位且保留其余Credit、Cast和Tag。Work始终显示“仅作上下文”，未保存候选标为“已在当前关系中”，不得误称“已保存”。
- 不创建实体、不写识别建议或修改已有建议的接受／拒绝状态，不触发扫描、自动化、激活或Manifest Push；沿用原关系保存的revision、事务、状态校验和Manifest dirty行为。无需schema／GraphQL／Manifest或迁移格式变更。

## 实施顺序与验收

1. 多实体匹配、稳定顺序、别名去重、Work 消歧、首位 Cast、原子保存和激活回归。
2. 安全成员随机访问接口、ZIP Store／TAR 和可验证的 7z 布局；覆盖压缩、加密、重复路径、源替换、越界 Range 和取消。
3. 接入 FFprobe／Poster／日期处理，优先直接输入，临时提取仅为派生；确保任务有终态、不永久 Pending。
4. 认证播放能力与前端双语拒绝提示，禁止存档播放触发代理任务；同步帮助与迁移／Manifest 回归。

schema v20 已部署，不得原地修改。优先实时只读能力检查，不持久化宿主机偏移；若确需新表，另建前向迁移并补齐可移植边界。无独立 Work 关系或 Manifest 格式升级。
