# Gallery详情双布局首版

## 已确认范围

- 只修改Gallery详情媒体列表，Gallery封面、搜索、实体页及大图布局不变。
- 同时保留当前3:4卡片网格与等高自适应行；按首版部署后的用户反馈，切换控件放在详情页右上角、收藏按钮左侧，使用两个36px紧凑图标按钮，不另占媒体区域工具栏。保留双语Tooltip／无障碍名称及当前选中状态；默认卡片网格，以浏览器localStorage保存跨Gallery偏好。存储不可用时仍可切换，不存数据库。
- 两种布局都保留现有Photo／Selfie、动画、视频的既有分组与顺序、每组24项渐进展开、全量大图上一项／下一项顺序和URL深链；不补洞、不重排、不添加分类标题。
- 切换不重建媒体DOM，不改变生成任务、动画锁定窗口、收藏／设封面／媒体菜单。尽量保持最靠近视口顶部的可见媒体位置；文档尾部受最大滚动范围约束。

## 实现

1. 在路径无关的GalleryMember索引新增`previewWidth`／`previewHeight`，由现有当前READY／STALE派生记录的宽高读取；0表示未知／尚无派生图。没有额外源文件读取、图片解码或数据库schema变更，也不修改Manifest／迁移包。
2. 等高行算法按原序顺序分配，目标行高240px，上限300px，间距12px，单项框宽不超过480px；按加入下一项前后的行高与目标差距决定换行。一般图片按实际比例显示，尾行左对齐且不强行撑满。
3. 极端比例的布局框限定在0.35～2.4，以`object-fit: contain`保留完整画面并允许留白；未知比例使用3:4稳定占位，不在图片加载后改排，避免跳动。尺寸上限可能让普通行也留出部分空白，这是首版有意的保守边界。
4. ResizeObserver测量媒体区域宽度并重排，缺少该API时监听window resize；布局只调整同一MediaTile节点的位置／尺寸。等高行取消现有悬浮放大，避免重新裁切。
5. 首版继续使用既有CARD_480／STATIC_POSTER／动画预览资源，不增加960／1600任务。高DPI锐度、行高、特殊比例留白及尾行效果待实际业务体验后调整。
